⌨️ Typing Speed Test

A simple Typing Speed Test desktop application built with Python and Tkinter. The application measures typing speed (WPM), accuracy, and elapsed time while providing real-time character highlighting.

✨ Features
🎯 Random typing sentences
⏱️ Real-time timer
⚡ Words Per Minute (WPM) calculation
🎯 Accuracy calculation
🟢 Highlights correct characters
🔴 Highlights incorrect characters
📊 Live performance metrics
🔄 Restart test functionality
🏆 Performance rating after completion
🌙 Dark-themed graphical interface
🖥️ Simple and user-friendly GUI

The project contains six predefined typing sentences and selects one randomly for each new test.

🛠️ Technologies Used
Python 3
Tkinter – GUI development
Time – Timer and performance calculation
Random – Random sentence selection
📊 How It Works
Start Application
       ↓
Random Sentence Selected
       ↓
User Starts Typing
       ↓
Timer Starts
       ↓
Characters Compared
       ↓
WPM + Accuracy Calculated
       ↓
Sentence Completed
       ↓
Final Performance Result

The timer starts automatically when the user enters the first character.

The application calculates WPM based on the number of words typed and elapsed time, while accuracy is calculated by comparing typed characters with the target sentence.

🚀 How to Run
1. Clone the repository
git clone https://github.com/Sachinkr606/TypingTest
2. Open the project
cd typing-speed-test
3. Run the Python file
python typing_test.py

Replace typing_test.py with your actual Python filename if different.

4. Start typing

The application will:

Select a random sentence.
Start the timer when you begin typing.
Calculate WPM and accuracy in real time.
Show your final performance when the sentence is completed.
